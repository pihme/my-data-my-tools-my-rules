## Why it fits

An individual can install the app for private use without payment. Source is published under a source-available license.

## Getting started

Prerequisites (from the official docs):

- An Android device

Steps:

1. Download FUTO Keyboard from the official site (keyboard.futo.org redirects to keyboard.futo.tech).
2. Install it and enable it as an input method in Android's keyboard settings.
3. Select it as the active keyboard and follow the in-app setup, including optional voice input.

Official site and downloads: <https://keyboard.futo.org/>
