Garage is a distributed object-storage system with an S3-compatible API, aimed at self-hosted and geo-distributed setups. Canonical repository is on git.deuxfleurs.fr; a GitHub mirror exists under deuxfleurs-org/garage. LICENSE text verified as GNU AGPL version 3 via the GitHub mirror raw file (direct raw fetch from git.deuxfleurs.fr was blocked by a bot check at verification time).

## Why it fits

You can run your own object store without a paid software license for private use.
