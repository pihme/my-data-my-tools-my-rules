## Why it fits

It is licensed under GPL version 2 or, at your option, version 3. Desktop installs are free for private use; sync is optional and under your control.

## Getting started

Prerequisites (from the official docs):

- A Windows, macOS or Linux computer

Steps:

1. Download KeePassXC for your operating system from the official download page.
2. Install it and create a new database with a strong master password.
3. Optionally enable the browser integration and install the KeePassXC-Browser extension.
4. Optionally sync the database file between devices with a file sync tool.

Official downloads: <https://keepassxc.org/download/>

## Notes

Not a hosted password service. Browser integration and sync tools are separate choices.
