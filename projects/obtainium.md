## Why it fits

Free to install for private device management.

## Getting started

Prerequisites (from the official docs):

- An Android device
- Permission to install apps from Obtainium

Steps:

1. Download the Obtainium APK from the official site or the GitHub releases page.
2. Install it and grant permission to install apps.
3. Add an app by pasting its source URL, for example a GitHub releases page.
4. Let Obtainium check for and install updates.

Official site: <https://obtainium.imranr.dev/>

GitHub README and releases: <https://github.com/ImranR98/Obtainium>
