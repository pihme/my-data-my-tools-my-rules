# Changelog

## 2.0 (unreleased)

### Added
- Card paragraphs: every entry has a 2–4 sentence summary (what it is, what it replaces, how you run it).
- Project logos on cards and project pages where the logo license or brand guidelines allow it, with credit; letter tile otherwise. Licensing decisions tracked in `projects/MEDIA.md`.
- Screenshots on project pages (16:10, with caption, credit, license and source) where a reusable license is stated.
- Audience indicator (End user / Enthusiast / Expert) on cards and project pages.
- Filter bar grouped into License, Runs as and For, with "Reset filters" and an empty state.
- New projects: Restic, Paperless-ngx, Beszel, Uptime Kuma, ONLYOFFICE and OpenCode; new categories Monitoring and AI.
- Structured funding information with source links on project pages.
- Funders page (FUTO, NLnet) with each organization's mission in its own words and the projects it funds.
- Omakase page (a short personal selection, shown once its content file exists).
- Selection criteria on the About page; "Suggest a project" issue form.
- Markdown support for fenced code blocks, numbered steps and callouts in dossiers.

### Changed
- "hand-picked" is now "curated"; the "All projects" entry is now "Catalog".
- About page starts with "What belongs here", followed by the selection criteria.
- Vaultwarden getting-started link points to the Using-Docker-Compose wiki page.
- US spelling throughout; compact, horizontally scrolling category chips on mobile; mobile spacing fixes (merged after 1.0, first released with 2.0).
