## How projects are selected

A project is listed when it meets all of these:

1. **You can run it yourself.** Anyone can install and run it on their own device or server.
2. **Free for private use.** Self-hosting or installing it for personal use costs nothing.
3. **The source is public.** Open source (OSI-approved license) or source-available. Every entry shows its license as a label, so you can tell the two apart.
4. **Checked at the source.** License, links and other facts come from the project's own repository or website and carry a "checked" date.

Things that are shown but never decide inclusion:

- **App or Server.** Each entry is labeled as an app you install on a device, a server you host, or both.
- **Audience.** A rough guide to how much technical experience you need to run it: End user, Enthusiast, or Expert.
- **Funding and support.** If a project is funded or backed by an organization (for example FUTO or NLnet), the dossier says so with a source. Funding alone says nothing about the license.
- **Ties to large companies.** Noted for transparency, not a reason to exclude a project.
