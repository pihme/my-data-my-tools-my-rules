Backrest

GPL-3.0-only
Open sourceSelf-host

Backrest is a web interface and scheduler for restic. It creates or imports restic repositories, runs backups, prune and check jobs on a cron schedule, lets you browse and restore files from snapshots, and sends notifications. It runs as a single binary on Linux, macOS, Windows and FreeBSD or in Docker, and downloads a suitable restic version if none is installed.

Bitwarden clients

GPL-3.0-only
Open sourceApp

The Bitwarden clients are the official password manager apps by Bitwarden, Inc.: the web vault, browser extensions, desktop apps and the command-line tool bw; Android and iOS have separate apps. By default they connect to Bitwarden's hosted servers, but each client can be pointed at a self-hosted server instead, such as a Bitwarden server or a compatible one like Vaultwarden.

Frigate

MIT
Open sourceSelf-host

Frigate is a network video recorder for IP cameras that runs object detection on the camera feeds locally in real time. It records around the clock or keeps recordings based on detected objects, offers live view with low latency, re-streams camera feeds and talks to other systems over MQTT. It runs as a Docker container, and a separate integration connects it to Home Assistant.

Kopia

Apache-2.0
Open sourceSelf-hostApp

Kopia is a backup and restore tool for Windows, macOS and Linux. It stores encrypted, compressed and deduplicated snapshots in a repository on a local disk, a NAS, an SFTP or WebDAV server, or S3-compatible and other cloud storage that you pick and pay for yourself. It comes as a command-line program and as KopiaUI, which runs as a desktop app or as a web interface in server mode.

OpenCloud

Apache-2.0
Open sourceSelf-host

OpenCloud is a self-hosted platform for storing, syncing and sharing files. Users get a personal space and shared team spaces in a web interface, with desktop and mobile apps for syncing. The Go server needs no database and keeps all data in the file system; sign-in uses OpenID Connect with a built-in identity provider or an external one such as Keycloak.

PhotoPrism

AGPL-3.0-only
Open sourceSelf-host

PhotoPrism is a self-hosted app for browsing, organising and sharing photos and videos, including RAW files and Live Photos. It labels pictures by content and location, recognises faces, offers search filters and world maps, and can be installed as a web app on phones. Vikunja

AGPL-3.0-or-later
Open sourceSelf-host

Vikunja is a self-hosted task manager for personal to-do lists and team projects. Tasks live in projects that can be shown as a list, Kanban board, table or Gantt chart, with labels, due dates, reminders, sharing and CalDAV access.
