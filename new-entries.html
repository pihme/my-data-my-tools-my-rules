Actual Budget

MIT
Open sourceSelf-hostApp

Actual Budget is a local-first app for envelope budgeting. It runs as a desktop app on Windows, macOS and Linux without any server, or as a self-hosted sync server that serves the web app and syncs budgets between devices, with optional end-to-end encryption. Bank sync is optional and needs your own API keys from a third-party provider.

Audiobookshelf

GPL-3.0-only
Open sourceSelf-host

Audiobookshelf is a self-hosted server for audiobooks and podcasts. It streams your library to the browser and to companion apps for Android and iOS, keeps listening progress per user across devices, downloads podcast episodes and fetches metadata and cover art. Ollama

MIT
Open sourceSelf-hostApp

Ollama runs open-weight language models on your own computer. It ships as a desktop app for macOS and Windows and as a command-line tool and background service for Linux, and serves a local API on port 11434 that tools such as Open WebUI or OpenCode can use. Ollama, Inc. also offers optional cloud models that need an account; they can be switched off.

Open WebUI

LicenseRef-OpenWebUI
Source-availableSelf-host

Open WebUI is a self-hosted chat interface for language models. It runs in Docker or via Python, keeps chats, users and settings in its own data volume, and connects to a local Ollama or to any OpenAI-compatible API; it has no models of its own. Its license is BSD-3-Clause with an added clause that forbids removing the Open WebUI branding, so it is labeled source-available.

Pi-hole

EUPL-1.2
Open sourceSelf-host

Pi-hole is a DNS server for your home network that blocks ads and trackers for every device that uses it. It runs on a Raspberry Pi, any small Linux machine or in Docker, needs a fixed IP address, and includes a web interface for block lists and query logs. Devices use it once your router hands out its address as DNS server.

Amperfy

GPL-3.0-or-later
Open sourceApp

Amperfy is an iOS, iPadOS and macOS app that plays music, podcasts and radio from an Ampache or Subsonic-compatible server. It supports several accounts, an offline mode, CarPlay, gapless playback, an equalizer, replay gain and scrobbling. It is a client only, so you need a music server such as Ampache or another Subsonic-compatible server.
