# My Data, My Tools, My Rules

A wiki-style directory of open-source projects that help people stay digitally self-determined and independent of big tech platforms.

The site will be a static site published with GitHub Pages, in the same way as [Freigeist](https://github.com/pihme/freigeist). Structure, inclusion criteria and design are still being worked out.
